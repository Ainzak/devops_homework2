# probe-stack

Учебный сервис для домашнего задания № 2 по дисциплине «Инструменты DevOps».
Тот же `probe` с заметками в базе, что в четвёртой лабораторной, но с драйверами
`psycopg2` и `mysqlclient`: при установке они компилируются из исходников.

## Что умеет

| Метод и путь | Что отвечает |
|---|---|
| `GET /` | строка со словом-маркером и именем хоста |
| `GET /me` | JSON: ФИО, группа, слово-маркер, имя хоста, версия, к какой базе подключено приложение |
| `POST /notes` | записывает заметку из поля `text`: `curl -X POST <адрес>/notes -d text=...` |
| `GET /notes` | все заметки из базы |

Таблицу `notes` приложение создаёт само при первом обращении.

Ионов И. Э., БИСТ-23-ПО-2. Префикс `ionov-01`, маркер `sitelab`.
Оба этапа сборки используют `python:3.12-alpine`. Стек: две реплики приложения,

Реестр публикуется на порту `6001`, база наружу не публикуется.

## Запуск

На одноузловом стенде Ubuntu с установленными Docker Engine и curl:

```bash
bash deploy.sh 5.0
curl -fsS http://127.0.0.1:8003/me; echo
curl -fsS -X POST http://127.0.0.1:8003/notes -d text=ionov-01-sitelab; echo
bash deploy.sh 5.1
curl -fsS http://127.0.0.1:8003/notes; echo
```

Скрипт включает Swarm, создаёт локальный реестр с политикой перезапуска,
собирает и публикует указанную версию, затем дожидается развёртывания стека.
Реестр привязан к этому одноузловому стенду: `localhost` не подходит для
развёртывания того же решения на нескольких узлах без изменения адреса реестра.
В обновлении используются `start-first`, healthcheck и автоматический откат.
`/notes` проверяет не только HTTP, но и доступность базы.

Данные лежат в томе `ionov-01_homework2_data`, образы реестра — в
`ionov-01-homework2-registry`. Они сохраняются при повторном запуске и
обновлении. Используется только учебный пароль `lab` из методички.
Объекты маркируются `devops.homework=2`; скрипт отказывается заменять
одноимённые службу или реестр другой работы. Порты 8003 и 6001 должны быть свободны.

## Переменные окружения

| Переменная | Что задаёт | По умолчанию |
|---|---|---|
| `DATABASE_URL` | адрес базы: `postgresql://логин:пароль@хост:порт/база` или `mysql://…` | нет, без неё `/notes` отвечает 503 |
| `MARKER` | слово-маркер в ответах | значение `MARKER_DEFAULT` |
| `APP_PORT` | порт внутри контейнера | `5000` |

## Версия

Читается из файла `/app/VERSION`, который пишется при сборке строками
`ARG VERSION` и `RUN echo "$VERSION" > /app/VERSION`. Нет файла — `dev`.
Каждая заметка хранит версию, которая её записала.

## Сборка

Первый этап устанавливает компилятор и заголовки, собирает C-драйверы в
`/venv`. Второй получает только окружение, приложение и библиотеки запуска.
`ARG VERSION` находится во втором этапе; версия записывается в `/app/VERSION`.
